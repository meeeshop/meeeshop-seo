================================================================================
TROUBLESHOOTING
================================================================================

Problem: "401 Unauthorized" in logs
Solution: SHOPIFY_ACCESS_TOKEN is wrong or expired
         Regenerate in Shopify Admin > Apps & integrations > API credentials

Problem: "[AI] all providers failed — using fallback"
Solution: No AI keys are set, which is fine
         Script will use hardcoded 2.3x multiplier
         This is completely normal!

Problem: "SHOPIFY_ACCESS_TOKEN not set in environment"
Solution: Secret wasn't added to GitHub
         Follow STEP 2 above to add it

Problem: Workflow doesn't run at 9 AM
Solution: GitHub Actions may have a delay
         Check Actions tab to see if it ran
         Can also manually trigger with "Run workflow" button
